Ingest and Review: different jobs, one overlap

They aren't the same, but the app makes them feel like they are. Ingest brings new material in and shows what Ken did with it. Review is where Ken asks you to decide something. The overlap: everything an ingest is waiting on (rulings, tickets, held page edits) shows up in both places, and the Ingest badge counts the same items Review does (sourcesWaiting(review.items)).

Ingest · bring knowledge in
  • Drop a transcript, recording, document or notes
  • Ken reads it into a dated note
  • Shows the summary, takeaways, what it overturns and contradictions
  • Lists what Ken wrote (page edits, ideas, escalations, tasks), each with Open and Undo
  • Seen / Undo all / Read it again
Review · decide
  • Proposed page changes and stale documents
  • Files Ken couldn't read
  • Edit and sync conflicts (keep mine, use theirs, accept Ken's merge)
  • Ingest waits: rulings, tickets, held edits (also on Ingest)
  • Approve, discard, run now, ignore this file
