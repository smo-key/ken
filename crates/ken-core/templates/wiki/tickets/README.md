# Tickets

One file per piece of work, `{{KEY}}-001.md`, copied from `Templates/Ticket.md`. The work in flight and the work done: what was asked, the evidence, the wrong turns and how it ended. A ticket is never deleted; a cancelled one says so in its status.

On the Log, an open ticket with an assignee is an action. A ticket with `type: milestone` marks a milestone instead: listed under Milestones, reached when it is done.
