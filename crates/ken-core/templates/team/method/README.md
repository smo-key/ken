# method/

The shared definition: steps, presets, gates, core fields and the rules for adding to them. Not here: what this team adds → `team/`.

`presets.json` is the source of truth, and prose pages cite it, never copy it. It is the method's `presets/presets.json`, which this template does not carry yet, so a person copies it in at set-up.

Changing anything here is a `process` ticket carrying the incident behind it. Configuration is data, so a process change is reviewed, diffed and reverted like any other change.
